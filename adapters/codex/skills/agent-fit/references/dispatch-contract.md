# 派发契约模板

仅在原授权、收益、配置和能力检查完成后填写；模板不额外授予权限。引用真实材料，敏感信息不进入普通日志。作用域查询使用未固定 task_delegate，显式传入冻结组合；fork_turns="none" 时需完整交接必要上下文。

```text
目标与原职责：
允许动作 / 禁止动作：
权威材料及其版本：
独占写入目录（只读取证则写明只读）：
已有修改及必须保留的内容：
必要上下文、依赖与工具：
原验收与最小充分验证：
配置证据：configuration_revision、skill_revision、effective_scope、完整 task_profile
请求组合：mode_id、level、task、model、effort
接续次数：attempts_used_before、additional_dispatches、attempts_used_after
停止条件与未知项：
返回：职责、精炼结论、产出与证据位置、核验结果、未覆盖与阻塞；未知/异常/部分结果标 PARTIAL
```

## 上下文与产物交接

任务说明须自包含：提供必要目标、权威材料及版本、约束、已有修改、依赖与验收，避免复制无关历史。按任务提供材料，不把岗位接力摘要作为唯一事实来源；通过文件、文档或结构化产物传递状态，主代理保留全局意图与关键决策。摘要不能替代核验所需的原始证据，文件引用须确认子代理可访问。

独立审查使用新的评估上下文，提供需求、待审产物与证据，将作者解释、假设和已证实事实分开，不把作者结论作为审查前提。保留安全背景、适用规则和必要决策依据；角色名称或更换线程本身不保证消除同模型盲区。当前宿主显式组合继续使用 `fork_turns="none"`，它只隔离对话历史，不证明无全局规则影响或具备文件、权限隔离。

回传精炼结论与可访问的产物、证据位置；失败、反例、验证状态和未确认项不能因压缩而省略。完整日志留在授权位置，必要时引用，不默认复制进主上下文。

## 停止与复用

子任务完成即返回，不因角色名称常驻等待或扩展工作。仅在后续任务确实受益于已有上下文、且不会破坏独立性要求时复用；主代理先重新核对授权、职责、材料版本及配置，适用的计数与停止条件仍按原规则执行。新任务重新查询配置并冻结快照；若新组合无法在既有代理上落实，另行派发，不以复用声称已切换模型。需要独立判断时使用新的评估上下文。

## 次数与职责边界

次数均为主代理发起的原任务累计次数；additional_dispatches 是本次拟新增的0或1次，attempts_used_after = attempts_used_before + additional_dispatches，且不超过3。拆分困难部分仍沿用原任务计数。宿主内部重试未知时不追加，旧写入者停止未知时不接管同范围。该模板是交接材料，不是自动计数或宿主执行证明。

子代理不是唯一参与者：先读适用规则和实际材料，不撤销他人改动；共享产出只有一个负责人。不能递归派发、修改生产/共享环境/第三方系统/代理配置或自行换模型。主代理保留最终设计、共享裁决、集成、关键验证与完成声明。
