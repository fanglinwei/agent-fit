## 使用边界

- Skill 与 AGENTS 提供指令约束，CLI 不拦截宿主派发，也不强制执行自然语言权限。
- 磁盘配置、宿主加载、供应商响应身份和当前会话匹配分别核验；独立 CLI 检查不能替代 fire 的会话验证。
- 校准结果只覆盖冻结任务。当前委派场景与历史校准证据从[文档导航](README.md)查阅；过期试验定义与原始输出不随发行包交付，不据此承诺通用质量、提速或费用优势。
- Linux/Windows、其他客户端、全部 Node 22.x、读屏器、真实 ChatGPT OAuth 推理、系统凭据库及长期稳定性仍需分别验证。
- 多文件更新采用逐文件原子替换和普通失败回退；不保证断电或崩溃时整体原子，也不防御恶意本机进程。残留锁须人工核对。
