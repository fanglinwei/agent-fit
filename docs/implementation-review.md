# 内测实现与验收

日期：2026-10-15。当前工作区版本为 0.6.0；本记录只描述当前配置格式。

## 当前约定

- 内置档位的命令、配置 id、状态记录、生成 JSON、查询和网页统一为 `cut / official / high / fire`，不保留名称映射。
- Skill 名称、目录和调用方式统一为 `subagent-delegation` / `skills/subagent-delegation` / `$subagent-delegation`；CLI 为 `sub-d`。
- 仅支持当前状态格式和版本。不提供旧版本兼容、旧目录识别、升级迁移、旧命令别名或 Python 安装入口。
- 不支持的状态格式、路径或档位引用返回 `STATE_INVALID`；版本不一致返回 `VERSION_MISMATCH`。校验在写入前完成，不转换或覆盖已有配置。
- 更换版本前使用原版本 `restore`，再安装并 `setup`。当前版本的同版本重复配置、档位切换、自定义和首次恢复基线保持有效。

## 保留的能力

四种内置档位、自定义四级主/备用组合、状态和选择解释、账号/目录检查、本地网页真实 CLI 操作，以及配置写入后的重启提醒。

状态与恢复记录、文件归属、路径、符号链接、权限、摘要、版本冲突和独占锁继续校验。逐文件原子替换、普通失败回退和并发编辑保护继续生效。恢复保留安装前内容、管理区块外修改及无关文件。

委派规则继续保留用户选择优先、难度与职责分离、禁止递归、独占写入、局部阻断、最小充分验证及 PARTIAL 返回。

## 使用边界

Skill 由 AGENTS 入口及角色指令要求读取，没有宿主委派拦截器。模型目录列出不证明账号请求权限；实际验证使用独立 Responses 请求，无工具和项目材料；请求成功与供应商报告的身份分别核验。缺少身份元数据仍不通过，不验证供应商内部上游路由。当前真实供应商对 Astra/ultra 返回 HTTP 400 / model_not_found，失败记录已保存。本次从该供应商 /models 读取到 13 个候选，其中无 Astra；目录来源及结果已按 home 保存，未自动执行真实批量推理。第三方候选通过自己的 /responses 验证，默认参数可调用与指定强度严格验证分别呈现，目录变化后停止批量调用。

未验证其他操作系统、全部 Node 22.x、真实桌面会话加载、读屏器、真实 ChatGPT OAuth 推理或系统凭据库授权验证。多文件操作不保证断电/崩溃时整体原子；残留锁需人工核对。并发保护不提供对恶意本机进程的内核级比较交换。
