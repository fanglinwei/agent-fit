# 内测实现与验收

日期：2026-10-14。当前工作区版本为 0.5.0；本记录只描述当前配置格式。

## 当前约定

- 内置档位的命令、配置 id、状态记录、生成 JSON、查询和网页统一为 `low / mid / fire`，不保留名称映射。
- Skill 名称、目录和调用方式统一为 `subagent-delegation` / `skills/subagent-delegation` / `$subagent-delegation`；CLI 为 `sub-d`。
- 仅支持当前状态格式和版本。不提供旧版本兼容、旧目录识别、升级迁移、旧命令别名或 Python 安装入口。
- 不支持的状态格式、路径或档位引用返回 `STATE_INVALID`；版本不一致返回 `VERSION_MISMATCH`。校验在写入前完成，不转换或覆盖已有配置。
- 更换版本前使用原版本 `restore`，再安装并 `setup`。当前版本的同版本重复配置、档位切换、自定义和首次恢复基线保持有效。

## 保留的能力

三种内置档位、自定义四级主/备用组合、状态和选择解释、账号/目录检查、本地网页真实 CLI 操作，以及配置写入后的重启提醒。

状态与恢复记录、文件归属、路径、符号链接、权限、摘要、版本冲突和独占锁继续校验。逐文件原子替换、普通失败回退和并发编辑保护继续生效。恢复保留安装前内容、管理区块外修改及无关文件。

委派规则继续保留用户选择优先、难度与职责分离、禁止递归、独占写入、局部阻断、最小充分验证及 PARTIAL 返回。

## 验证

环境：macOS、Node.js 24.19.0，以及已有 Chrome / Playwright。所有配置测试使用临时 home。

| 检查 | 结果 |
| --- | --- |
| Node 测试 | 101 项通过，0 失败或跳过；包含统一 id、配置与生成 JSON 一致、不支持格式/版本零写入、冲突、回退、查询、恢复与服务验证 |
| Chrome 集成 | 配置、自定义创建/保存/激活、冲突保留与比较、目录检查错误、规则解释、恢复和键盘焦点通过；四页在 375/768/1280/1440px 无页面溢出，零脚本错误；不支持的配置版本明确报错、禁用应用且零写入 |
| 隔离 npm 包 | 26 个公开运行/文档资产，仅提供 sub-d；无 Python/旧 Skill 资产；安装、三档 id、自定义和恢复通过 |

已删除专属于移除功能的升级迁移测试、Python 兼容入口和历史安装器 fixture；配置安全与恢复回归测试继续运行。

## 使用边界

Skill 由 AGENTS 入口及角色指令要求读取，没有宿主委派拦截器。模型目录列出不证明账号请求权限；实际推理因无法证明严格工具隔离继续返回 `PROBE_ISOLATION_UNSUPPORTED`。

未验证其他操作系统、全部 Node 22.x、真实桌面会话加载、读屏器或真实模型推理。多文件操作不保证断电/崩溃时整体原子；残留锁需人工核对。并发保护不提供对恶意本机进程的内核级比较交换。
